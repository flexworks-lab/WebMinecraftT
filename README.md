# webminecraft ⛏️ 

> **A lightweight, voxel-based sandbox engine built for the browser.**

`webminecraft` brings the classic block-building and exploration experience directly to your web browser with zero downloads required. Built with modern web technologies, it features procedural terrain generation, dynamic block placement, and a smooth first-person physics engine—all running natively in your browser.

## 🌟 Features

* **Zero-Install Gaming:** Jump into a world instantly. No launchers, no installations, just pure browser-based gameplay.
* **Procedural Terrain Generation:** Infinite, randomized voxel landscapes generated using Perlin/Simplex noise.
* **Seamless Block Interaction:** Dig, mine, and build with real-time chunk updating and dynamic mesh rendering.
* **Smooth FPS Controls:** Fluid pointer-lock camera mechanics and custom collision detection for natural movement.
* **Highly Optimized:** Utilizes [Three.js / WebGL / WebGPU] for efficient rendering, chunk meshing, and fast load times.


## 🎮 Controls

The control scheme is designed to feel familiar to traditional first-person sandbox games:

| Action | Key / Input |
| :--- | :--- |
| **Move Forward** | `W` |
| **Move Backward** | `S` |
| **Move Left** | `A` |
| **Move Right** | `D` |
| **Jump** | `Spacebar` |
| **Sprint** | `Shift` (Hold) |
| **Destroy Block** | `Left Click` |
| **Place Block** | `Right Click` |
| **Select Block Type** | `1` - `9` |
| **Pause / Release Mouse** | `ESC` |
