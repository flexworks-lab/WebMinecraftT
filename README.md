# WebMinecraftT

A small Minecraft-style voxel sandbox that runs in your browser.

**Play:** https://flexworks-lab.github.io/WebMinecraftT/

Still a work in progress. Expect unfinished features and bugs.

HAS ONLINE GAMEPLAY 

## Run locally

```bash
git clone https://github.com/flexworks-lab/WebMinecraftT.git
cd WebMinecraftT
npm ci
npm run dev
```

Built with Three.js, Vite, and Node.js.

Browser version only.
